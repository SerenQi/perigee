# 涨落：接你自己的状态

「涨落 · Ebb」在底栏，是一页**空模板**。它自己不产生任何数据，你自己的程序或 Claude 推什么，它就显示什么。一共四块：

| 块 | 显示什么 | 怎么写进去 |
|---|---|---|
| 天色 | 页头下面一行小字，比如"晴 · 有点累 · 第 12 次心跳" | `POST /ebb/sky` |
| 指标 | 两列细条，每条一个 0~1 的数。几条、叫什么、点开的说明，全由数据决定 | `POST /ebb/metrics`（整组替换） |
| 活动 | 最近 7 天每种 `kind` 各多少条，一根分段条 | 由事件自动统计 |
| 时间线 | 每一次做了什么，按日期排 | `POST /ebb/events`（追加） |

数据存在网关的 `data/ebb.json`。事件只留最近 30 天（环境变量 `PERIGEE_EBB_KEEP_DAYS` 可改）、最多 1000 条。

下面的例子都在服务器本机执行。网关默认地址是 `http://127.0.0.1:3003`；从浏览器那一侧访问时，前面要加反向代理前缀 `/api`。

## 天色

```bash
curl -X POST http://127.0.0.1:3003/ebb/sky -H 'Content-Type: application/json' \
  -d '{"text":"晴 · 有点困 · 今天第 3 次醒来"}'
```

传空字符串就清掉这行。

## 指标

每次推送都会**整组替换**。`value` 取 0~1，`desc` 是点开那条之后看到的说明，可以不填。

```bash
curl -X POST http://127.0.0.1:3003/ebb/metrics -H 'Content-Type: application/json' -d '{
  "metrics": [
    {"key":"energy",  "label":"精力", "desc":"还能干多少活", "value":0.72},
    {"key":"focus",   "label":"专注", "desc":"注意力集不集中", "value":0.55},
    {"key":"curious", "label":"好奇", "desc":"想不想往外看看新东西", "value":0.31},
    {"key":"tired",   "label":"疲惫", "value":0.18}
  ]
}'
```

最多 24 条。页面按数值从高到低排，顶上会写"此刻最高"是哪一条。

## 事件（时间线）

```bash
curl -X POST http://127.0.0.1:3003/ebb/events -H 'Content-Type: application/json' \
  -d '{"kind":"code","text":"修好了登录页的样式","note":"顺手加了个暗色模式"}'
```

- `kind`：一个短词，决定时间线上用哪个图标、在活动条里归到哪一类。下面这些有专门的图标：`message` `code` `read` `music` `out` `study` `memory` `wake` `sleep` `skip`。别名 `chat` `book` `play` `travel` `walk` `learn` `note` `listen` `idle` `defer` 也认。别的词也能用，图标会显示成一个小圆点。
- `text`：一句话，必填。`note`：补充说明，可以不填。
- `at`：时间（ISO 格式），不填就是现在。

清空所有事件：`curl -X DELETE http://127.0.0.1:3003/ebb/events`

## 读

```bash
curl 'http://127.0.0.1:3003/ebb?days=7'
# → { sky, metrics, events（新的在前，最多 200 条）, counts: { days, total, by_kind } }
```

## 给 Claude 用

把 [给你的Claude看.md](给你的Claude看.md) 里"涨落"那段抄进 `CLAUDE.md`，Claude 每次做完一件事就会自己记一条。你也可以写个定时脚本，从别的地方（日程、健康数据、你自己的状态引擎）算出指标推进来。
