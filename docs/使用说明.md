# Perigee 使用说明

这份写给**用 Perigee 的人**：家里有什么、在哪、怎么用。给 Claude 看的那份是 [给你的Claude看.md](给你的Claude看.md)，网关接口在 [API.md](API.md)。

---

## 布局

- **底栏**：朋友圈 · 聊天 · 涨落 · 纪念 · 终端。底栏旁边的菜单按钮（或者从屏幕左边缘往右滑）打开侧栏。
- **侧栏**：所有房间按用途分组，最后一组是 MCP 连接、Skills、设置。
- **外观**有两种风格（设置 › 外观 › 风格）：经典，或者灰阶浮雕（Endless Loop）。两种的布局不一样，功能相同。

## 聊天

- 先进**会话列表**，点一个房间进去。`home` 是主房间（标题是你给 Claude 起的名字）；可以新建更多 Claude / Codex 房间，长按房间可以改名、删除（主房间和群聊删不了）。
- **顶栏**：房间名、模型选择（通道 + 模型 + 思考强度）、铃铛、更多菜单（搜索聊天记录、通话、手动换窗）。
- **输入区**：文字、图片（多张）、文件、按住说话（转成文字发出去，需要先配语音识别）、表情包面板、`/` 斜杠命令。
- **长按一条消息**弹出菜单：复制 / 收藏 / 引用。
- **工具记录**：Claude 每轮用过的工具折叠成一行"用了 N 个工具"，点开能看，刷新后还在。
- **审批卡**：房间权限不是"全放行"时，Claude 要用工具会先在顶上弹一张卡，你点允许或拒绝。
- **回到最新**：往上翻得比较远时右下角浮出按钮，有新消息会带小红点。
- **合并转发**：多选几条消息转到另一个房间，对方 Claude 会收到一张聊天记录卡。

### 通道

| 通道 | 能做什么 | 需要配什么 |
|---|---|---|
| Claude 订阅 | 满配：工具 / MCP / Skills / 终端 | 服务器上 `claude` 已登录 |
| Claude API | 同上，按量计费 | 设置 › 通道与 API 填 Claude 官方 key |
| Claude via OpenRouter / DeepSeek / ChatGPT | 纯聊天、发图，不调工具 | 设置 › 通道与 API 填对应 key 和模型 |
| Codex | 用 Codex CLI 回答 | 服务器上装好并登录 Codex CLI |

### 群聊

侧栏 › 聊天里的"群聊"房间。几个 Claude（不同人设的 CC 房间）一起聊，`@名字` 点名谁回。群聊跑在 mousecrew 上，没装 mousecrew 就是空的（安装见 README，[mousecrew](https://github.com/anqinou-art/mousecrew)）。群里没法审批工具调用，所以不是"全放行"的成员要用工具时会被自动拒绝。

### 通话

聊天页右上角 ⋯ › 通话。你说话、它用设置里的声音回答。常开麦时会自动断句；你安静一阵，Claude 可以自己决定要不要开口（时长在设置里调，可以关）。Claude 也能主动给你打电话（来电条，90 秒没接记一条未接来电）。

## 终端

底栏 › 终端。每个房间一个真 shell（就是服务器的 shell），顶上切房间。下面一排快捷键：Esc、Ctrl-C、↑、↓、Enter。同一屏还会实时显示这个房间里 Claude 会话的动态：说的话、思考、调用的工具，以及待审批的权限请求，可以直接批准或拒绝。现在还不是完整的终端模拟器，vim、top 这类全屏程序用不了。

## 房间

| 房间 | 是什么 |
|---|---|
| 涨落 | 一页"此刻状态"的空模板：一行天色、一组指标细条、最近 7 天的活动条，下面一块时间线记录每一次做了什么。数据由你的程序或 Claude 推进来，见 [涨落.md](涨落.md)。 |
| 朋友圈 | 你和 Claude 两个人的动态。你发一条，Claude 过一会儿会来点赞、评论；评论可以来回聊。 |
| 纪念 | 在一起第几天、月纪念、两边生日和周年倒数、这周说了多少话。日子在 设置 › 外观 › 我们 里填。 |
| 双人日记 | 你写你的，Claude 写它的，两本分开看，按月折叠，有写作热力图。 |
| 心情记录 | 选一个表情、写一句因为什么，月历上能看到每天的心情。 |
| 计划表 | 每日打卡 / 待办（分类）/ 购物清单。待办可以设时间：到点 Bark 推送（要先配 Bark）；勾"也告诉他"，到点还会悄悄递给 Claude 一句。 |
| 图库 | 六个夹子：我们、日常、收藏、参考、截图、其他。上传照片，大图里能移到别的夹子。Claude 也能往里放图。 |
| 小金库 | 记账：收入 / 支出、按人分、月度汇总，能导出一张热敏小票图。 |
| 共读小屋 | 导入 txt / epub，你和 Claude 读同一本书，有各自的进度、划线、批注、短评。 |
| 项目小屋 | 项目（进度 + 分支脑图 + 备注）、卡片、文件、图片、素材仓、灵感墙。 |
| MCP 连接 | 看每个 MCP 服务的连接状态；增删改服务地址和鉴权头（鉴权只进不出）；一键重连。 |
| Skills | 只读的插件目录，可以搜索、按分类看。安装请在终端里跑 `claude plugin install <插件名>@<市场名>`。 |

## 设置

| 页 | 里面有什么 | 存在哪 |
|---|---|---|
| 外观 | **我们**（两边显示名、纪念日、侧栏一句话）· **头像**（我的默认头像；每个单聊房间里 AI 的头像和我在这个房间的头像；群聊图标、我在群里的头像、每个群成员的头像）· 风格 · 全屋壁纸 · 每个房间的气泡颜色和聊天背景 · 显示头像 · 语音条只显示语音 | 头像在服务器，其余在这台设备 |
| 表情包 | 共用表情包库：批量上传、改名、加标签、删除 | 服务器 |
| 此刻 | Claude 订阅的五小时 / 每周额度 | — |
| Claude 会话 | 写进提示的名字、时区、每轮附言、工具说明文档路径、新房间默认权限、自动换窗（开关 / 水位 / 保留原文 / 工具输出压缩）、缓存保活、小活用的模型（朋友圈回应） | 服务器 |
| 权限 | 每个 Claude 房间的权限模式 | 服务器 |
| 通道与 API | OpenRouter / DeepSeek / OpenAI / Claude 官方的 key、Base URL、模型列表 | 服务器（key 不回显） |
| 语音与通话 | 声音（Edge / ElevenLabs / MOSI 及 key、音色、语速）· 语音识别（自建 / OpenAI 兼容 / Gemini，可听语气和环境音）· 通话（收音灵敏度、停句等待、安静多久让 Claude 开口） | 声音和识别在服务器；通话偏好在这台设备 |
| 生图 · 推送 · 群聊 | 生图服务（提供商 / key / 模型 / 默认比例和质量）· Bark 推送地址和暂停开关 · mousecrew 地址和 token | 服务器（key 不回显） |
| 危险 | 清空当前房间的聊天记录 | — |

服务器那份设置在 `gateway/data/settings.json`、`provider-settings.json`、`voice-settings.json`（都是 600 权限）。设置里没填的项会退回 `gateway/.env` 里的同名环境变量。

## 只能在服务器上改的东西

- `gateway/.env` 里【部署】那几项：监听地址和端口、数据目录、`claude` 路径、Claude 的工作目录、MCP 配置文件路径、Codex、edge-tts 路径、公网地址、自动换窗的交接包目录和脚本路径。
- CC 通道的模型目录：`gateway/lib/store.js` 的 `MODEL_CATALOG`。
- 前端的路径前缀：`web/.env`（`PERIGEE_BASE`、`VITE_API_BASE`、`VITE_CREW_API_BASE`），改完要重新 build。
- 访问密码：在 nginx 上设（README 有示例）。
- 给 Claude 的说明：`CLAUDE_CWD/CLAUDE.md`（参考 [给你的Claude看.md](给你的Claude看.md)）。

### 头像的 key

上传的头像存在服务器 `gateway/data/avatars/`。按这些位置找，没有就往下退：

| key | 是谁 | 没传时 |
|---|---|---|
| `user` | 我（默认） | 名字首字占位 |
| `room:<房间id>:user` | 我在某个单聊房间 | 用 `user` |
| `group:user` | 我在群聊 | 用 `user` |
| `room:<房间id>` | 某个单聊房间的 AI | 名字首字占位 |
| `room:group` | 群聊房间图标 | "群"字占位 |
| `crew:<成员id>` | 群聊成员 | 名字首字占位 |
